# Upaon-Açu V15 — Deluxe

Grand strategy histórico em HTML/CSS/JavaScript, pronto para GitHub Pages.

## V15
- Mantém as correções das V8–V14.
- Economia viva com consumo, preços, excedentes, escassez e carga de infraestrutura.
- Painel de conselho com fluxo anual e pulso geopolítico.
- Decisões rápidas de reserva, feira e manutenção logística.
- Pixel-art e atlas vintage incorporados localmente.
- Retratos e identidade visual dos povos.
- Canvas/SVG continuam disponíveis para evolução do mapa.
- Layout responsivo para desktop, notebook, iPad e celular.

## Arquitetura
HTML/CSS/JS + TypeScript de referência + JSON + SVG + Canvas + ferramentas Python.
Sem backend e sem dependências externas obrigatórias.


## V16 — Auditoria e correções

V16 preserva a V15 e concentra-se em robustez: validação de recursos em projetos, consistência de tratados de paz, migração de saves V15/V14, limite rígido de 5 AP, zoom consistente até 1,8× e validações estáticas adicionais.
